# Lettering font

Place a **.ttf** or **.otf** here to use it for storyboard lettering (dialogue and narrative boxes) instead of the default system font.

- **Preferred name:** `lettering.ttf` — used first if present.
- **Setting labels (bold):** `lettering-bold.ttf` — if present, setting/location boxes use this; otherwise the script simulates bold from `lettering.ttf`.
- Otherwise the first alphabetically sorted .ttf/.otf in this folder (excluding names containing “bold”) is used.

## Comic-style fonts (free)

For a more comic-book look, add one of these (download the TTF/OTF and put it in this folder):

- **Comic Neue Angular** — legible comic style (OFL). All variants: [ComicNeue-Angular folder](https://github.com/crozynski/comicneue/tree/master/Fonts/TTF/ComicNeue-Angular) (Regular, Bold, Italic, BoldItalic, Light, LightItalic). Recommended: save [Regular](https://raw.githubusercontent.com/crozynski/comicneue/master/Fonts/TTF/ComicNeue-Angular/ComicNeueAngular-Regular.ttf) as `lettering.ttf`, [Bold](https://raw.githubusercontent.com/crozynski/comicneue/master/Fonts/TTF/ComicNeue-Angular/ComicNeueAngular-Bold.ttf) as `lettering-bold.ttf`.
- **Tomson Talks** — comic dialogue font (OFL). [GitHub](https://github.com/frabru/TomsonTalks) · [direct TTF](https://raw.githubusercontent.com/frabru/TomsonTalks/master/TomsonTalks.ttf).
- **Comic Neue** (round) — [comicneue.com](https://comicneue.com/) or [GitHub](https://github.com/crozynski/comicneue).
- **LibreComic** — comic lettering (CC0). [Codeberg](https://codeberg.org/sotha1/LibreComic-font) · [direct OTF](https://codeberg.org/sotha1/LibreComic-font/raw/branch/main/LibreComic.otf).
- **OpenComicFont** — [GitHub](https://github.com/arthurpizza/opencomicfont) (TTF/WOFF, free).

Rename your file to `lettering.ttf` to make it the default, or leave the original name (it will be used if it’s the only font here).
